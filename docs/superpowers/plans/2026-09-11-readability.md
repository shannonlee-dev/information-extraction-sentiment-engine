# Python 가독성 정리 계획

**Goal:** 프로젝트의 Python 코드를 명시적인 제어 흐름과 의미 있는 이름으로 정리한다.

**Architecture:** 기존 모듈과 공개 API를 유지한다. 데이터, 계산 순서, 정렬 순서, 출력 형식은 바꾸지 않는다.

**Tech Stack:** Python 3.10 이상, pytest, matplotlib.

**Spec:** 사용자가 요청한 프로젝트 전체 가독성 점검과 `docs/python-style.md`의 기준.

- [x] 모든 Python 소스와 테스트를 읽고 복합 표현을 조사한다.
- [x] 감성 분석의 역방향 검색, 부호 반전, 중첩 분기를 명시적으로 바꾼다.
- [x] 추출의 검색·검증·결과 병합과 평가 지표 계산을 단계별로 표현한다.
- [x] 보고서의 이스케이프·모드 선택·표 데이터를 정리하고 테스트도 같은 기준으로 검토한다.
- [x] 기존 전체 평가 JSON과 변경 후 JSON을 비교하고 전체 테스트를 실행한다.
- [x] 변경 코드를 독립 검토하고 스타일 기준을 문서로 남긴다.

검증 결과: Python 36개 파일 전체 점검 및 Black 형식 확인, Python 3.10 구문 검사,
전체 테스트 148개 통과. 기존 평가 데이터와 무작위 조합 1,000개의 분석 및 보고서
출력이 변경 전후 동일하다. 독립 리뷰의 정렬 표현 개선 의견도 반영했다.
